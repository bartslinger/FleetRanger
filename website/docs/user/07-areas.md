# Areas

Areas are named pieces of land, such as "North block", that you draw on a map. FleetRanger then shows how long each flight spent in each area, and you can filter flights and sessions by area.

Areas are off for a new organisation: an admin switches them on under [Administration](09-administration.md).

## Draw an area

1. On **Areas**, select **New area**.
2. Click the map for each corner, and close the shape by clicking the first corner again.
3. Enter a name and select **Save**.

To change or delete an area, select it and use the menu on its row.
