# Administration

**Administration** holds your organisation's settings. Only admins see this page.

## General

The **General** tab shows the organisation's settings. Select **Edit settings** to change them, then **Save**:

- **Name**: your organisation's name.
- **Time zone**: all times in FleetRanger are shown in it, the same for everyone.
- **Session gap**: in minutes. A break between flights longer than this starts a new session. See [Sessions](02-sessions.md#how-flights-form-sessions). It counts for flights that come in from then on; existing sessions stay as they are.
- **Areas**: switches [Areas](06-areas.md) on or off.

If your install offers AI assistants, this is also where you allow them to query FleetRanger.

If your install offers it, the **General** tab also has **Delete organisation**, which deletes the organisation and all its data at once. To confirm, you type the organisation's name. This can't be undone.

## Apps

If your install offers it, the **Apps** tab lets people open other web apps with their FleetRanger login. Select **New app**, enter its name and its **Return addresses**, and select **Add app**. On the app's page you can add roles for it, which you then give to people like FleetRanger's own roles.

## Who may do what

Only an **Admin** sees **Administration** and changes its settings.
