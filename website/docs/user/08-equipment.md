# Equipment

**Equipment** lists your remote controllers, drones and batteries, each on its own tab. FleetRanger adds them by itself from the flight logs, so there is nothing to enter.

Select a device to see its flights and figures, and to give it a name, such as the number painted on it. A battery's page shows how its capacity changes over time.

## Pair a controller

Select **Pair a controller** on the **Remote controllers** tab. [Getting started](01-getting-started.md#pair-the-controller) has the steps.

To stop a controller from uploading, for example one that was lost, open it and select **Remove pairing**.
