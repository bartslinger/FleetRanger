# Groups

Groups divide an organisation's work, such as a "North team" and a "South team". Every flight, session and controller is in a group, and people get their roles in groups. Only admins see this page.

A new organisation has one group, and FleetRanger doesn't show groups until you create a second one.

## Roles

| Role       | What it allows                                                              |
| ---------- | --------------------------------------------------------------------------- |
| **Viewer** | Sees the group's flights and sessions.                                      |
| **Pilot**  | Flies for the group: appears on the controller, and sees their own flights. |
| **Editor** | Sees and organises the group's flights and sessions, and writes comments.   |
| **Admin**  | Manages the whole organisation: all groups, users and settings.             |

Roles add up: someone who flies and organises the group's work gets **Pilot** and **Editor**.

## Create a group

Select **New group**, enter its name, and add its members on the group's page with **Add member**.
